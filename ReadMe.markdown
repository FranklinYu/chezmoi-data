# dotfiles managed by Chezmoi

This is intended to be deployed with [Chezmoi](https://www.chezmoi.io/).
Currently only supports macOS and Linux (mainly Debian and Arch Linux).

## Codex Cloud

In the environment setup conversation, enter:

> Extract https://codeload.github.com/FranklinYu/chezmoi-data/tar.gz/HEAD directly into `~/.local/share/chezmoi` with `--strip-components=1` (use a fresh directory if the destination is occupied). Follow `no-deploy/cloud-agent-setup.md` in the extracted source.
